# Project Roadmap

> Conget — простая CLI утилита для получения веб-контента с плагинной архитектурой и MCP интеграцией

## Milestones

- [x] **Базовая архитектура и CLI** — структура проекта, BaseFetcher интерфейс, entry-points
- [x] **Core CLI команды** — fetch, analyze, list, mcp
- [x] **Default fetcher (trafilatura)** — универсальный фетчер для любых URL
- [x] **GitHub fetcher** — README.md из репозиториев
- [x] **HH fetchers** — вакансии и работодатели через API
- [x] **MCP интеграция** — сервер для AI-агентов
- [x] **Library API** — класс Conget для программного использования — *требует разделения каждого main.py на cli.py и fetcher.py (CLI-обертка использует fetcher, без дублирования кода)*
- [x] **Специализированные исключения** — иерархия CongetError для продвинутой обработки ошибок
- [x] **Типизированные структуры** — dataclasses (FetcherMetadata, FetchResult, AnalysisResult)
- [x] **YouTube Video fetcher** — метаданные видео через yt-dlp
- [ ] **HTTP валидация** — Content-Type, Content-Length проверки — *нужно понять, с какими фетчерами это легко интегрируется, а с какими плохо*
- [ ] **Кэширование** — enable_cache, cache_ttl для оптимизации — *нужно проверить, насколько это легко интегрируется в каждый из фетчеров*
- [ ] **Интеграционные тесты** — покрытие основных сценариев (после стабилизации архитектуры)
